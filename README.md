# AC网在线OJ竞赛平台后端项目

## 项目简介
AC网在线OJ竞赛平台是一个在线编程评测系统，主要用于算法竞赛和编程练习。平台支持题目练习、在线考试、代码提交、结果评测、用户排名等功能。

## 技术架构
本项目采用微服务架构，主要技术栈包括：
- Spring Cloud Alibaba
- Nacos服务注册与发现
- Feign远程调用
- RabbitMQ消息队列
- Redis缓存
- MySQL数据库
- MyBatis Plus
- XXL-JOB分布式任务调度
- Docker沙箱环境用于代码执行

## 主要模块
1. **网关模块 (oj-gateway)**
   - 负责请求路由和权限控制
   - 实现统一的鉴权入口

2. **基础公共模块 (oj-common)**
   - 包含多个子模块，提供通用功能
   - 包括安全认证、Redis操作、文件存储、消息发送、MyBatis自动填充等基础功能

3. **业务模块 (oj-modules)**
   - **oj-friend**: 用户侧功能
     - 题目练习
     - 在线考试
     - 代码提交与评测
     - 用户信息管理
   - **oj-system**: 管理系统
     - 题目管理
     - 考试管理
     - 用户管理
   - **oj-judge**: 评测服务
     - Docker沙箱环境执行用户代码
     - 实现代码编译、运行、结果判定
   - **oj-job**: 定时任务
     - 处理考试排名
     - 维护缓存数据

## 核心功能
### 在线评测
- 支持Java语言的在线代码提交
- 使用Docker沙箱环境确保代码执行安全
- 实现内存和时间限制的检测
- 提供详细的运行结果反馈

### 考试系统
- 支持定时考试
- 实现考试排名
- 维护考试缓存提高性能
- 支持考试发布与取消发布

### 用户系统
- 手机验证码登录
- JWT令牌认证
- 用户信息管理
- 用户状态管理

### 管理系统
- 题目管理
- 考试管理
- 用户管理
- 权限控制

## 系统特色
- **高性能缓存设计**：广泛使用Redis缓存，提高系统响应速度
- **消息队列解耦**：使用RabbitMQ解耦代码评测流程
- **分布式任务调度**：通过XXL-JOB处理定时任务
- **安全的代码执行环境**：Docker沙箱确保用户代码安全执行
- **模块化设计**：清晰的微服务架构，便于扩展和维护

## 数据库设计
使用MySQL数据库，主要包含以下表：
- 用户表(tb_user)：存储用户基本信息
- 题目表(tb_question)：存储题目信息
- 考试表(tb_exam)：存储考试信息
- 考试题目关联表(tb_exam_question)：维护考试与题目的关系
- 提交记录表(tb_user_submit)：存储用户代码提交记录
- 考试用户关联表(tb_user_exam)：维护用户与考试的关系

## 安全机制
- 使用JWT实现无状态认证
- 敏感数据加密存储（如用户密码）
- 接口权限控制
- 请求参数校验
- 异常统一处理

## 部署建议
1. 准备MySQL、Redis、RabbitMQ、Nacos等基础服务
2. 配置各模块的application.yml文件，设置正确的服务地址和数据库连接
3. 按顺序启动基础服务：注册中心 -> 网关 -> 公共服务 -> 业务服务
4. 导入初始化数据库脚本
5. 配置XXL-JOB调度中心
